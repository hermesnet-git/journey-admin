04Outros dois planos de fluxo

Descoberta de jornadas (plano administrativo)

  1. Channel Lab pede GET /api/lab/v1/journeys?channelType= ao BFF.
  2. BFF autentica no Admin Backend com credencial server-side e devolve só jornadas PUBLISHED.
  3. Navegador nunca recebe usuário, senha ou token do Admin.

Bootstrap efêmero (Web e Mobile)

  1. Lab cria POST /api/lab/v1/bootstraps com journeyId, target, variáveis.
  2. BFF guarda em memória (TTL 10 min) e devolve um token opaco.
  3. O host troca o token por GET /api/lab/v1/bootstraps/{'{token}'}, valida o próprio alvo e inicia a instância sozinho.

05Dependências de pacotes

Os renderers já têm formato de SDK — falta só publicá-los.

Confirmado no código: os quatro pacotes são versionados (semver próprio), não importam nada deste emulador — a dependência corre só até sdui-contract/sdui-runtime-*, headless — e têm build que compila para dist/ com tipos .d.ts. Isso é a forma de um SDK. O que falta pra virar um de verdade: os quatro estão marcados "private": true (ou publish_to: none no Dart) e o ponto de entrada aponta pro código-fonte (./src/index.ts), não pro dist já compilado — hoje só um workspace npm/pub que enxerga o monorepo consegue importar. Nenhuma mudança de arquitetura: destravar publicação é private:false (ou registry interno) + apontar exports/main/types pro dist + um README de consumo.

06Fronteiras que a arquitetura protege

Um só cliente do ms-journeyNenhum host chama Camunda, ms-espec-registry, Strapi ou o próprio ms-journey diretamente — sempre via Emulator BFF.
Admin é só catálogoA execução da jornada nunca depende do Admin Backend; ele só responde "quais jornadas estão publicadas".
Contrato sem frameworksdui-contract e sdui-runtime-* nunca importam Mística, React Native ou Flutter UI.
Nada de credencial no navegadorTokens do Admin e tokens de bootstrap não chegam ao cliente nem aos logs (rota mascarada em sanitizedLogPath).
WCE é descartávelBridge + Web UI ficam atrás de um contrato próprio; podem virar um BSP real sem tocar no contrato SDUI ou no ms-journey.
Estado só em memóriaBootstraps e sessões de WhatsApp vivem no processo do BFF; reiniciá-lo descarta os dois.
